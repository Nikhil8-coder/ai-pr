An interactive, responsive, and robust **AI Career Guidance System** utilizing **First-Order Production Rules Logic** and **Propositional Chaining Matrices** to match personal preferences with career paths.

## 🛠️ Step-by-Step Workspace Setup & Deployment
To install this repository stack completely onto local local nodes or launch it straight into your cloud engine, execute the standard sequences below:

```bash
# Step 1: Clone this repository into your workspace path
git clone https://github.com
cd career-choice

# Step 2: Provision required software library packages
pip install -r requirements.txt

# Step 3: Spin up the dynamic inference engine script
streamlit run app.py
```
